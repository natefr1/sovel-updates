    What protects it

    Private storage
    LUKS2 home image, AES-256-XTS, 512-bit key, argon2id, recovery key
    Vault
    gocryptfs folder, AES-256-GCM, its own passphrase, closes on every lock
    Separation
    Separate Linux user, compositor, clipboard, notifications, search and display profiles
    Lock order
    Cover every output, confirm, then quiet JARED, clear clipboard, close Vault, switch VT
    Normal Mode
    No JARED button, dock icon, shortcut, widget or Settings page. The binary refuses to start it.
    Not covered
    Administrators and root, and a compromised kernel. An open session keeps its key in memory until you exit or seal.
