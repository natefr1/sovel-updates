# Sovel Desktop 0.1.0-9 Workspace

Open **Settings → Software Update → Check for Update**, install Workspace, and restart Sovel.

## Changes

- **Displays.** Arrange monitors, identify outputs, choose resolution and refresh rate from reported modes, change scaling and rotation, set per-monitor wallpapers, and choose whether the menu bar and dock follow the primary display. Configuration changes can be reverted automatically. Super+Shift+arrow moves the focused window between outputs.
- **Files.** Tabs, split browsing, breadcrumbs, Recent, Starred, previews, search, Downloads and a persistent transfer queue. Downloads started in Files can use a chosen folder or optional file-type categories. Completion notifications can open the containing folder. Removable storage appears before mounting and can be mounted, unmounted or safely ejected. Automatic USB mounting is optional while Files is open. Archive tools handle ZIP, 7Z, TAR, TAR.GZ, TAR.XZ and GZ.
- **JARED.** Local Notes, Projects and Research, scoped file search, previews on a chosen monitor and approval before importing unchecked tasks or TODO lines from notes. The volume and audio-output approval paths were exercised in the VM. Whisper input and Piper speech run on the CPU. Voice models and the Piper runtime are opt-in downloads. Qwen3.5 4B can be selected through a compatible local Ollama installation, with the 1.7B model available as a fallback.

## Validation and limits

- All 16 regression suites passed. The build VM verified a two-output desktop, window movement, output-disable recovery, timed layout rollback, archive and transfer integrity, project and note operations, and real HTTPS downloads and research retrieval.
- The VM upgrade completed from 0.1.0-8 with zero package removals. All 37 Store listings and the greeter are preserved.
- Physical monitor reconnection, USB devices and GTX 1070 inference still need testing on the target PC. Sovel Files shows files downloaded by browsers. Control of a browser's active downloads stays in the browser. Advanced display calibration, HDR, saved positions for third-party windows, bulk rename, undo and redo, and cloud or network locations remain future work.
