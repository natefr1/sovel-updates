# Sovel Desktop 0.1.0-11 Private Access

Install Private Access from **Settings → Software Update** and sign out and back in. This fix update gives Normal Mode a visible way into Private Mode and keeps JARED available until Private Mode is set up.

## Changes

- **JARED stays until setup.** JARED, its widgets, Super+J and its Settings page stay in Normal Mode until Private Mode is set up on the computer. After setup and one sign-out, JARED lives only in Private Mode.
- **A way in.** The Sovel menu shows **Set Up Private Workspace…** before setup and **Open Private Workspace…** after it. **Settings → Private Workspace** now opens in Normal Mode with *Open Private Workspace*, *Set up Private Workspace* and *Run isolation check*. Normal Mode never shows private settings.
- **Guided setup.** *Set up Private Workspace* opens a terminal that previews every change, asks before making it, creates the encrypted account, then moves your JARED data into it. It needs an administrator password and shows a recovery key once.
- **Super+Shift+P always responds.** Before setup it opens the setup page. If the private sign-in service is not running, it says so and does not lock. After switching, it confirms that the active VT really changed.
- **City wallpaper in Normal.** On first start, Normal Mode resets once to the city wallpaper, clearing an old photo or live wallpaper. The violet landscape, spider emblem and laboratory are offered only in Private Mode.
- **Fixes.** The isolation check and private audit log open from Settings again. New command: `sovel-mode doctor` explains whether Private Mode can be reached, without showing private content.

## Validation and limits

- Built for Ubuntu 26.04 with Qt 6.10.2. 17 of 18 suites pass there, including Dual Environment, modes, settings, workspace, core and appearance. The installer connection-state check needs installer files that are not part of the desktop package.
- Not yet run on hardware: the guided setup terminal, the Sovel menu entry and VT switching after setup. If Super+Shift+P does not reach the private sign-in, run `sovel-mode doctor` and `journalctl -t sovel-mode`.
- An administrator account can read an open private workspace. Remove `sudo` and `adm` from the everyday account once you have a separate administrator account.
