# Sovel desktop 0.1.0-5

- Files has a new purple sidebar, familiar folder locations, mounted drives, breadcrumbs, search, list/grid views and sorting. Copy, move, rename, create folder, move to Trash and restore from the home Trash are available. Existing folders and files are preserved.
- Right-click an app in App Library to pin or unpin it. Drag pinned dock icons to reorder them; the order is saved. App Library stays at the end.
- The dock retains running apps when minimized. Clicking an app restores its existing window and state; clicking the active app minimizes it. A running app's dock menu also lists its windows.
- Files, Settings, Store and App Library reuse their existing window when launched again. Opening a specific folder can still create another Files window.
- Downloaded `.deb` files open Package Installer. It shows package details and a dependency/change review before the user confirms installation through system authorization. Signed online update verification remains enforced.
- External **Waypaper 2.9** and **mpvpaper 1.9** replace the built-in Motion app. Open Waypaper from Settings, Store or App Library, choose a folder and select a still image or local video. Video is silent by default and pauses behind maximized windows. Selecting a built-in Sovel wallpaper stops the external background. Steam Workshop project playback is not claimed.

Install from **Settings → Software Update**, then restart Sovel to load the new desktop and file associations. This is an online desktop update; the existing USB ISO has not been rebuilt for this release.

Validation: all seven automated test suites passed; real compositor tests preserved the same App Library window through minimize/restore and relaunch; a benign local package passed dependency review, installation, file verification and removal through the real system package service. Dock drag reordering and native Files/Library/Store/Package Installer views were checked. The external Waypaper window, video decoding and automatic pause behind a maximized window passed in the software-rendered VM session; performance on the secondary PC is not yet verified.

The reported GTX 1070 full-system lockup and physical Foxtec Wi-Fi/Bluetooth operation remain unverified on the secondary PC. File Trash browsing currently covers the home Trash, not every removable drive's Trash.
