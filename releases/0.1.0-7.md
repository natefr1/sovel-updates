# Sovel Desktop 0.1.0-7

Install from **Settings → Software Update → Check for Update**, approve installation, and restart Sovel. This is a public-channel update for the existing Qt/Labwc desktop. The USB ISO is unchanged.

## Five updates

- **Sound:** Settings now has Output, Input, Applications and Advanced pages. Select monitor/HDMI/DisplayPort, USB, Bluetooth and other devices exposed by the audio service; control volume, mute and stereo balance; test left/right speakers; select and test microphones with a live meter and local five-second recording; route and control individual app streams. Device profiles and explicit PipeWire sample-rate/buffer preferences are available where supported. The top-bar music-note button opens quick controls. App lists remain stable during refresh, and requested routes are confirmed with bounded retries. Equalizer/noise processing is provided by the external optional EasyEffects app, available through Store search, rather than fake built-in controls.
- **Mini JARED:** Open from the top-bar star, App Library or **Super+J**. Local conversations use the official [Qwen3-1.7B model](https://huggingface.co/Qwen/Qwen3-1.7B-GGUF). Choose **Download local model** once: 1,834,426,016 bytes (1.83 GB), checked against a pinned SHA-256 before installation. No model is bundled in the desktop update. CPU mode is the conservative default, and the model unloads after two idle minutes. Conversations stay on the computer. Arithmetic/time/memory and reviewed app/audio/Bluetooth actions work without downloading the model. Model replies cannot execute commands; system actions are allowlisted and separately approved, and locking always requires approval. Preferences include optional offline spoken replies, execution mode, idle unloading, and background residence. Voice input and wake phrases are not implemented in this release.
- **Bar activation:** Native edge input regions reveal the dock and menu bar over maximized apps. A top-positioned dock shares activation with the menu bar. Settings → Desktop & Dock adds automatic hiding, four dock edges, sensitivity, reveal/hide delays and animation timing. Popup and pointer activity hold the relevant surface open.
- **Bluetooth names:** Advertised friendly names replace address-shaped aliases. Paired devices can be renamed; custom names persist. Device category and available battery percentage are shown. Addresses remain available under Advanced Details.
- **Calendar:** Click the clock for a monthly grid, today highlighting, previous/next month and Today. The calendar follows the locale's first weekday and handles leap years and year boundaries.

## Preservation and limits

All 23 existing Store listings are preserved; no remove/uninstall operation is added. The greeter source, launcher and configuration hashes are unchanged. Existing pinning, drag ordering, window restoration, local package installation and wallpaper integration remain.

The larger Settings roadmap is deferred. Labwc still provides the coordinated translucent surfaces described in release 6, without compositor backdrop blur/refraction. The optional GNOME package is unchanged. This update does not claim to fix the reported physical GTX 1070 monitor-input hard lockup. Physical HDMI/DisplayPort audio, USB/Bluetooth hardware behavior and full-refresh-rate performance still require testing on the actual PC.

## Validation

All 13 automated suites passed. Isolated live PipeWire tests verified output/default changes, volume/mute/balance, per-app routing (including selection during a refresh and repeated route changes), microphone metering/recording, and distinct captured left/right speaker channels. Audio subscriptions were checked for self-polling loops. Approved JARED volume/output changes and cancellation were tested against the real isolated audio service. The actual Qt HTTPS downloader completed and verified the full pinned model; real local Qwen inference and model unloading were exercised.

Real Labwc tests verified eight repeated reveal/hide cycles over a maximized app, all four dock edges, shared top-edge activation, calendar outside/Escape dismissal, actual GUI slider output changes, screenshot save/clipboard byte equality, menu outside/Escape dismissal and same-window App Library minimize/restore/relaunch. Package upgrade from 6 to 7, rollback to 6 and reinstallation of 7 completed with zero package removals and a clean package audit.
