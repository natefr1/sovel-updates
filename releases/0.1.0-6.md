# Sovel desktop 0.1.0-6

Install from **Settings → Software Update → Check for Update**, approve installation, and restart Sovel. This updates the existing Qt/Labwc desktop; the greeter and default session are preserved. The USB ISO is unchanged.

- Shell bars, context menus, popups, widgets and tooltips use coordinated purple translucent surfaces. Menus dismiss on outside click, Escape, selection or focus loss, and opening another menu closes the previous one. JARED opens on hover/click without a hover tooltip.
- The dock animates changes to its width and item layout. Existing pinning, drag reordering, App Library placement and same-window minimize/restore remain available.
- App icons resolve from desktop-file metadata, full Flatpak IDs, Snap exports, theme directories and app-provided paths, with a generic fallback.
- Noto multilingual and emoji fonts plus Fcitx5 input engines add Japanese, Chinese, Korean, Hindi, Arabic and Russian input support after sign-in. Existing input profiles and choices are preserved; use Fcitx5 Configuration to select additional engines.
- Win+Shift+S selects an area, saves a PNG to Pictures/Screenshots, copies it to the clipboard and shows a preview notification.
- Settings can select downloaded PNG, JPEG, WebP and other supported image files. External Waypaper/mpvpaper integration remains available.
- Labwc uses the wlr capture portal with PipeWire; the voice buffer minimum applies only to matching Discord/Vesktop clients. **Vesktop is available in Store as the maintained Discord-compatible screen-sharing alternative**; this system update does not silently install a Flatpak into a user's account.
- Store retains all 20 previous curated apps and adds Discord, Vesktop and Hidamari. Retired listings remain visible. Backend operations are allowlisted, and uninstall/remove/remote-delete paths are rejected. Search, screenshots, app details and installation are preserved.
- Shell hover/menu/dock/native-app transitions use eased timing and respect reduced motion.

Current Labwc supports real translucency but **does not provide compositor backdrop blur/refraction or universal external-app window animations**. The separate optional GNOME 50 extension implements live compositor blur; it is not installed or enabled by this Qt/Labwc system update. Custom GNOME refraction/saturation effects are not implemented. Physical-PC Discord calls, NVIDIA stability and full-refresh-rate performance remain unverified.

Validation: all nine automated suites passed. Real isolated compositor tests verified screenshot save/clipboard bytes, menu Escape/outside dismissal and same-window restore. A real 1280×720 BGRx frame was received through the Wayland portal and PipeWire. Mozc converted and committed Japanese into a Qt field. A silent Discord-named Pulse client received the scoped voice minimum. Normal-user installation, rollback to 0.1.0-5 and reinstallation of 0.1.0-6 completed with zero package removals. The installed Settings view rendered successfully. Greeter source and launcher hashes are unchanged.

Updates continue to require the existing signed Sovel repository and independently signed distribution dependencies. No signing key or trust policy is replaced by this release.
