# Sovel Desktop 0.1.0-8 — Horizon

Install from **Settings → Software Update → Check for Update**, approve installation, then restart Sovel. This is a public-channel update for the existing Qt/Labwc desktop. The USB ISO is unchanged.

## The full Horizon update

- **Settings:** 29 grouped, searchable pages with back/forward navigation, favorites and recent pages. Appearance supports light/dark/automatic modes, accent, type size, supported desktop preferences and local profiles. Device pages expose actual capabilities and unavailable-device explanations. Account photo, startup apps, default apps, local language selection, diagnostics consent and fixed administrative actions are integrated. The wallpaper picker accepts downloaded images. Unsupported cloud services and enforcement controls are not simulated.
- **Wi-Fi:** Nearby and saved networks, hidden-network connection, band/signal information, connection progress, disconnect and forget. Scan requests have bounded timeouts; stale networks expire, and adapter hotplug and resume trigger a fresh device inspection. Opening passive status does not continuously scan.
- **Menu bar:** Choose status icons and their order, visibility, opacity and clock format. Quick controls expose actual network, Bluetooth and audio state; Control Center and the monthly calendar remain available. Popup ownership and dismissal keep closed or destroyed menus from trapping shell input. Compact layouts preserve useful controls at smaller widths.
- **Software Update:** Horizon has a public release name, type, icon and notes, plus installation history. Build, publication, download and installation times have distinct sources. Publication details are accepted only from signature-verified Sovel repository metadata with a matching Packages checksum. A time absent from older installations is shown as not recorded; the client does not invent a publication or download time.
- **Store:** All 23 previous listings remain, with **14 additions**: ArtCraft, Prism Launcher, Bottles, LocalSend, KDE Connect, Mission Center, EasyEffects, Gear Lever, Upscayl, OpenRGB, Czkawka, Kooha, Warehouse and Logseq. App details retain source and permission review. Supported background jobs continue when Store closes, with progress, queued cancellation, retry, update discovery and update actions. Flatpak uses signed Flathub; KDE Connect uses the existing signed native package sources; ArtCraft uses its official release with a pinned SHA-256. No Store uninstall/removal operation is accepted, and native installation rejects package removals.
- **Widgets:** 24 types with persistent local layout/content, three sizes, opacity, refresh and positioning controls. Notes, lists, timers, reminders, clocks and calendars join real resource, network, battery, download, media and update information. GPU information appears only when the driver exposes it. Weather uses an explicitly chosen city and opt-in Open-Meteo access, with forecast, caching and attribution; disabling permission cancels requests. Local foreground usage collection is optional and can be cleared. No automatic location request is made.

## Validation and preservation

All 16 native automated suites passed, including Store preservation, radio lifecycle, popup/chrome, Settings, updates and widgets. All 29 real Settings status reports ran successfully. Settings UI navigation, search and pages were checked in two themes and at two sizes; all 24 widget views rendered in Qt without QML errors. The final Settings refinement passed its targeted tests again.

Live signed LocalSend installation survived its launching client exiting; cancellation preserved the installed app, and a subsequent background update completed. Official ArtCraft download, pinned hash and desktop registration passed. Native KDE Connect installation completed. A real Labwc session verified calendar dismissal, Settings minimizing/restoring the same process and page, and immediate menu-bar preference propagation. Quiet desktop CPU measured about 1.4% in the single-CPU software-rendered build VM; this is not a hardware performance guarantee.

The package upgraded the VM from 0.1.0-7 to 0.1.0-8 with **zero package removals** and a clean package audit. The 23 original Store IDs and unchanged greeter source/launcher/configuration hashes are checked before release. Existing dock pinning, ordering, window restoration, local package installation and external wallpaper integration remain.

## Known limits

Assistant-specific work is paused at the user's request; the public version 7 JARED implementation is retained. This release does not claim to repair the reported assistant volume-command hang. Labwc surfaces remain coordinated translucency without compositor backdrop blur/refraction. The optional GNOME package is unchanged. Physical USB Wi-Fi/Bluetooth, GTX 1070 monitor-input recovery and full-refresh-rate performance still need verification on the actual PC. Weather requires a working internet connection; Flatpak and native app compatibility depend on their upstream packages.
