# Dependency ownership

New Sovel code in this bundle is supplied to the project owner. No upstream
Vitreus, Pleamar or GNOME extension source is incorporated in the new shell.
The original supplied HTML files informed interaction behavior; they are not
loaded by the application or bundled as an app renderer.

Qt, LayerShellQt, labwc, greetd, cage, swaylock and Linux are external dependencies
under their respective licenses. An eventual closed-source Sovel product must
still satisfy those licenses, including applicable notices, relinking rights,
and source obligations for modified copyleft components. Changing visible
branding does not change dependency authorship or license obligations.

The wallpaper assets were generated for this project with the built-in image
generation tool. New component source and the vector fallback are project
assets. This bundle does not include Apple app icons or third-party movie art.
